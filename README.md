# titze.consulting

Öffentliche Website (Onepager, DE/EN) und Designsystem für **Titze.Consulting** — unabhängige Beratung für die grabenlose Sanierung unterirdischer Infrastruktur.

Statische Seite ohne Build-Schritt, gehostet über GitHub Pages. Website und Visitenkarte bauen auf derselben Design-Token-Quelle (`styles/tokens.css`) auf.
